# Demo invitacion 15s

Demo React/Vite para vender invitaciones web personalizables.

## Personalizacion rapida

Edita `src/invitationConfig.js`. Ahi estan:

- `brand`: nombre, instagram y logo de Invitaciones Web.
- `hero`: titulo principal, bajada y etiqueta.
- `event`: fecha, horario, lugar, direccion y link de Google Maps.
- `rsvp`: fecha limite, WhatsApp y mensaje predeterminado.
- `style`: paleta completa de colores.
- `images`: hero, retrato y galeria. Pueden ser URLs o archivos dentro de `public/images`.
- `story`, `details`, `itinerary` y `sections`: bloques de texto y secciones editables.

El logo esta en `public/brand/invitaciones-web-logo.svg`.

## Comandos

```bash
npm install
npm run dev
npm run build
```
